# Free letter from Santa generator (one HTML file, one letter per child, nothing stored)

Add each child, type their first name, age and one kind or brave thing they did this year (plus an optional sibling, pet or elf name), pick warm or jolly, and print a personal letter from Santa for every child, one A4 page each, in one go. No sign-up, no server, no cookies, no build step: it is one `index.html` file.

**Use it now, no install:** download `index.html` and open it in any browser, or use the single-letter page version at [tchworks.co.uk/free/letter-from-santa-2026](https://www.tchworks.co.uk/free/letter-from-santa-2026/?utm_source=github&utm_medium=repo&utm_campaign=santa-letter-repo).

## What is in it

- Wording changes by age band (3 to 5, 6 to 8, 9 and over) and by style (warm and gentle, or jolly and silly).
- The kind thing you type is woven into the letter, so it reads as if Santa really knows.
- Never promises a particular present: Santa has read the list, and a good surprise is half the fun.
- Prints one letter per page with a red double border; the form and buttons are hidden when printing.
- Everything you type stays in your browser and is shown as text, never run as code.

## Tips

- Print on cream or slightly thicker paper if you have it.
- Fold in three, write the name on the envelope in red or green, and leave it by the tree or the stockings.

## Change it

Open `index.html` in a text editor. The letter wording is in the `letter()` function near the bottom.

## Limits

A fun keepsake, not an official or postal service.
